## 📖 Overview

**Quick Bike** is a web-based application built for bike rental businesses. It eliminates the need for manual logbooks by providing a digital dashboard to monitor the exact time a bike is rented, the total revenue each bike generates, and any expenses incurred due to damage or maintenance. 

The application features a clean, responsive interface built with vanilla web technologies, making it fast, lightweight, and easy to deploy on any static hosting provider.

## ✨ Key Features

*   **Time Tracking:** Accurately count and log the time spent on each rental.
*   **Revenue Management:** Track the total income generated by individual bikes.
*   **Expense & Damage Logging:** Record unexpected costs related to bike damage or repairs to maintain accurate profit margins.
*   **Lightweight Architecture:** Built without heavy frameworks for maximum performance and minimal load times.
*   **Responsive UI:** A clean interface accessible on both desktop and mobile devices.

## 🛠️ Tech Stack & Dependencies

Because this is a lightweight frontend application, it requires very minimal dependencies.

*   **Frontend Core:** HTML5, CSS3, Vanilla JavaScript (ES6+).
*   **No Build Tool Required:** The project can run directly in the browser (no Webpack/Vite required).
*   **Optional Dev Dependencies:** If you want a local development server, you only need a tool like `Live Server` (VS Code extension) or `http-server` (Node.js package).
